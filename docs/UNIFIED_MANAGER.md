# YourCourse Unified Manager

Устанавливаемый файл: `online-courses-editor.user.js`.

## Что изменено

Сохранены исходные алгоритмы Course Manager 1.2.4 (включая преподавателей) и Enrollments 1.4.1. Они выполняются в отдельных замыканиях и Shadow DOM внутри одного окна. Поля, вкладки, импорт, журналы, отчёты и независимые состояния сохранены. Исходные два файла не изменены.

Общее меню переключает разделы без остановки задач. Положение, размер, сворачивание и выбранный раздел сохраняются локально. Кнопки ⌖, ⛶, − управляют общим окном. CSS модулей изолирован от WordPress и друг от друга.

Сохранены исходные ключи GM, sessionStorage, доменные очереди, билеты переходов и проверки сохранения. Добавлена общая блокировка операций по домену с идентификатором вкладки Tampermonkey, проверкой владельца и продлением каждые 4 секунды. Блокировка переживает штатный переход; при закрытии вкладки освобождается по таймауту 25 секунд. Пауза активного рабочего процесса сохраняет блокировку до остановки или продолжения. Меню её не снимает. Повторный запуск во время получения блокировки запрещён.

Enrollments и его обработчики создаются только на `yourcourse.shop/wp-admin/admin.php?page=enrollments`. На остальных поддерживаемых страницах раздел показывает причину недоступности. Курсы и преподаватели доступны на исходных шести доменах, включая восстановление после авторизации. Наблюдатель ошибок Course Manager подключается только при работе его очереди; общее окно использует один ResizeObserver. Общая функция задержки вынесена в оболочку; функции видимости оставлены раздельными, поскольку их условия различаются.

Неопределённый Enroll Now требует ручной проверки даже после паузы, остановки или конфликта блокировок. Подтверждённый успех после штатного перехода переводит очередь к следующему курсу. Проверки Update и Update User после перезагрузки сохранены.

## Установка и сохранение данных

1. Остановите старые очереди и дождитесь окончания отправленного сохранения/зачисления. В Course Manager экспортируйте JSON-копии **обоих** режимов — курсов и преподавателей — на каждом используемом домене. Сохраните отчёты при неопределённом результате.
2. В Tampermonkey можно заменить содержимое существующей записи Course Manager новым объединённым файлом: её GM-хранилище сохраняется. Не удаляйте старую запись до экспорта резервных копий.
3. Если устанавливаете объединённый файл отдельной записью, GM-хранилище старого userscript недоступно новой записи. В каждом режиме откройте «Настройки» → «Восстановить резервную копию JSON». Восстанавливаются очередь, журнал и настройки; автоматический запуск отключён. Состояния неопределённого сохранения сохраняются для проверки через «Продолжить».
4. Отключите обе отдельные старые записи, если они остаются установленными. Одновременно должен работать только объединённый userscript. Файлы исходников в проекте остаются резервными копиями.
5. Для сохранения списка Enrollments используйте ту же вкладку и домен: исходный ключ sessionStorage сохранён. Закрытие вкладки может удалить эти данные, как в исходном скрипте. Положение старой отдельной панели не импортируется: объединённое окно имеет собственные настройки.

`@updateURL` и `@downloadURL` направлены на новый файл в прежнем GitHub-репозитории, ветка `main`. Обновление по этим адресам станет доступно после публикации файла в репозитории. Публикация в рамках этой задачи не выполнялась. Сохранены обе Excel-библиотеки; `@grant none` Enrollments заменён объединённым набором разрешений Course Manager.

## Проверка

Автоматическая проверка использует настоящий headless Chromium с локальным макетом страницы, подменёнными GM API и перехваченными переходами. Сетевые запросы к WordPress и изменения данных сайта не выполняются. Результаты находятся в `UNIFIED_MANAGER_TEST_RESULTS.txt`.

Проверены метаданные, наличие всех исходных именованных функций (позиционирование панели перенесено в оболочку), инициализация на шести доменах, поля обоих модулей и преподавателей, геометрия встроенного интерфейса, переключение и сохранение выбора, защита от повторного монтажа, блокировки между модулями и вкладками, Start/Test/Stop Enrollments, восстановление после отправленного/подтверждённого зачисления, JSON-восстановление настроек и очереди, однократный запуск курсов, билет перехода и страница входа. Синтаксис дополнительно проверен компиляцией через Node VM.

Для повторной сборки и проверки:

```powershell
python build-unified-manager.py
python test-unified-manager.py --browser "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

Исходник оболочки — `unified-manager-shell.js`; сборщик вносит проверяемые точечные адаптации в копии исходных модулей и формирует автономный userscript. Для установки нужен только итоговый `.user.js`.

На авторизованном WordPress ещё требуется проверить:

- Загрузку обеих Excel-библиотек в песочнице Tampermonkey, импорт реальных файлов и сохранение настроек после обновления страницы.
- «Один курс»: изображение, Title, slug, цена, Description, Update и сверку после перезагрузки.
- «Один профиль»: login, имя, Bio, фото, Update User и сверку сохранённых полей.
- Enrollments: сначала «Тест (1 курс)», затем реальное зачисление с проверкой Name, пагинации, Add, Enroll Now, Okay и следующего курса.
- Паузу/остановку во время операции, переходы, восстановление авторизации и конфликт двух реальных вкладок.

Локальный макет не подтверждает совместимость селекторов с текущей разметкой сервера и поведение реального POST. Все исходные функции сохранены, но полная функциональная эквивалентность на сайте требует этих проверок.
